# Jammy

The shared aux cord. Everyone queues, nobody touches your phone.

Jammy is a real-time collaborative music room. A host plays YouTube tracks through a custom player, guests join via QR code or short code from their own phones, and everyone adds songs to one shared queue that updates live for the whole room.

## Structure

- [`frontend/`](frontend) — Next.js web app
- `backend/` — Node/Express + Socket.io server (coming soon)
